# Learnings

## Platform
Web, GitHub Pages.

## Stack
Approved: zero-dependency static HTML/CSS/ES modules, Node standard-library tests.

## Users and purpose
Paul and public readers exploring a topic through a sourced report and experiments. A hub for multiple learning topics; Jev, Kev, and Laya-LiteRT are first.

## Capabilities and constraints
Read a comprehensive report, inspect typed requests and probabilities, experiment with thresholds, compare illustrative local examples with hosted Jev, a user-run local Kev endpoint, or on-device architectures (Kev via ONNX Runtime Web and Laya-LiteRT via Google LiteRT.js). Generate a validated demo specification using user-supplied OpenAI or Claude keys. No execution of generated code. Keys remain memory-only. No analytics, external fonts or runtime CDN.

Actual browser inference options include Kev (onnx-community/kev-0.6b-ONNX) via ONNX Runtime Web and Laya-LiteRT (litert-community/laya-LiteRT, from convaiinnovations/laya) via Google LiteRT.js (@litertjs/core) with classic Google LiteRT (.tflite) dual-graph architecture (main decision graph + act-head graph) using Wasm/XNNPack and WebGPU acceleration. Keep technical boundaries and evidence status prominent.

Only public, unauthenticated GitHub sources inform repository suggestions. No private data. Paid model requests require user action; no project-owned API credentials.

## Approved direction
Long-form readable report and split experiment workbench, light blue/ink palette, native controls, no generated images. Accuracy and explicit evidence status outrank marketing.
