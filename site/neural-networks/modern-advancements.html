The modern stack

Separate mathematical changes from memory-system improvements in current sequence models.

RMSNorm and rotary position embeddings

RMSNorm divides a vector by √(mean(x²) + ε), then applies learned gains. Unlike LayerNorm it does not subtract the mean. Scale the vector below: normalized components stay nearly fixed, with a small ε effect.

RoPE rotates pairs of Q and K components by position-dependent angles. Relative positions affect their dot product. Rotating preserves each pair’s norm; it does not add a position embedding to V. Change position below to inspect the rotated vector.

FlashAttention: same attention, different IO

Naive attention materialises an N × N score/probability matrix in high-bandwidth memory (HBM). FlashAttention processes Q/K/V tiles in fast on-chip SRAM and maintains running softmax maxima, denominators and weighted-value accumulators. It avoids writing the full attention matrix to HBM; it does not replace exact softmax with a sparse approximation.

The calculator uses asymptotic element-traffic expressions with omitted constants. SRAM capacity controls how much can be tiled, but hardware, occupancy, precision and kernel implementation determine actual speed. These numbers are not a benchmark, and increasing tile size indefinitely is not a free optimization.

MoE: sparse parameter activation

A mixture-of-experts router scores candidate feed-forward experts per token and selects a small subset. Our top-2 example normalises only the selected scores. Active parameters can be far fewer than total parameters, but routing, load balancing and device-to-device communication introduce costs. Attention layers and shared components are still used for every token.

Mamba: a different sequence operator

Mamba (2023) uses selective state-space updates instead of an all-pairs attention matrix. A simplified recurrence is hₜ = Aₜhₜ₋₁ + Bₜxₜ, yₜ = Cₜhₜ. Input-dependent selection governs what information is retained. The real architecture includes learned projections, discretisation and a hardware-aware scan; a fixed scalar recurrence would not reproduce it.

State-space decoding keeps a recurrent state rather than a growing attention KV-cache. This changes memory scaling but does not imply identical retrieval capabilities or universally better performance. Hybrid models may combine attention and state-space layers.

KV-cache: avoid recomputing the past

Autoregressive decoding stores earlier keys and values for each attention layer. The cache grows linearly with tokens and K/V heads. GQA, quantisation, eviction policies and paged allocation target different costs: fewer entries, fewer bytes per entry, bounded history or less fragmentation. A cache is not a model’s long-term memory; it belongs to an inference context.
