The modern stack

From the 2017 Transformer to modern foundation models, architectural evolution has proceeded along two distinct axes: mathematical reformulations that stabilize gradients and relative geometry (RMSNorm, RoPE, selective SSMs), and hardware-aware memory designs that eliminate IO bottlenecks (FlashAttention, Grouped-Query Attention, and KV caching).

RMSNorm: eliminating mean subtraction

In standard LayerNorm, an activation vector x ∈ ℝᵈ is centered by subtracting its mean μ before dividing by its standard deviation. Zhang & Sennrich (2019) demonstrated that the variance-scaling property accounts for the entire training stabilization benefit, while mean centering imposes unnecessary memory passes. RMSNorm scales directly by the root-mean-square:

RMS(x)=1d∑i=1dxi2+ϵ,y=xRMS(x)⊙γ

Because RMSNorm does not compute μ=1d∑xi, a fused GPU kernel requires only a single reduction pass over memory instead of two, reducing normalization kernel execution latency by up to 50%.

Rotary Position Embedding (RoPE)

Traditional Transformers add an absolute position embedding to input token representations: xm+pm. This alters activation norms and leaks position information into value vectors V. RoPE (Su et al., 2021) encodes position by rotating pairs of query and key coordinates in the complex plane.

For a d-dimensional embedding vector, RoPE groups elements into d/2 two-dimensional coordinate pairs (x2i,x2i+1). At sequence position m, pair i is multiplied by a 2D rotation matrix:

RΘ,m(i)=[cos(mθi)−sin(mθi)sin(mθi)cos(mθi)],θi=base−2i/d

Proof: dot products depend only on relative distance

Consider query q at position m and key k at position n. Their inner product under RoPE is:

⟨Rmq,Rnk⟩=(Rmq)T(Rnk)=qTRmTRnk

Because rotation matrices form the orthogonal group SO(2), the transpose equals the inverse rotation: RmT=R−m. Because 2D rotations commute:

RmTRn=R−mRn=Rn−m ⟨Rmq,Rnk⟩=qTRn−mk=⟨q,Rn−mk⟩

The attention score depends strictly on the relative displacement n−m. Furthermore, because orthogonal transformations preserve vector norms (‖Rmq‖=‖q‖), RoPE preserves embedding magnitude and leaves value vectors V untouched.

FlashAttention: exact attention without materializing N × N matrices

In standard attention, computing S=QKT and P=softmax(S/dk) writes an N×N matrix to High Bandwidth Memory (HBM). For sequence length N=32 768, an N×N FP16 matrix consumes 32 7682×2 B≈2.14 GB per head, per layer. Writing and reading this matrix over the memory bus saturates bandwidth.

The online softmax recurrence

FlashAttention (Dao et al., 2022) tiles Q, K, and V into blocks that fit entirely within fast on-chip SRAM (~192 KiB per Streaming Multiprocessor on NVIDIA H100). It maintains running softmax statistics without materializing the full matrix. For query tile Qi and key/value tile (Kj,Vj):

Sij=QiKjTdk,minew=max(miprev,rowmax(Sij)) ℓinew=emiprev−minewℓiprev+rowsum(eSij−minew) Oinew=emiprev−minewOiprev+eSij−minewVj

At the final block, the true normalized output is Oi=Oifinal/ℓifinal. The output is mathematically identical to standard attention to floating-point rounding precision.

IO complexity

Dao et al. proved that standard attention transfers Θ(Nd+N2) elements between HBM and registers, while FlashAttention transfers:

HBM TrafficFlash=Θ(N2d2M)

where M is on-chip SRAM capacity. For typical SRAM sizes (M≫d2), FlashAttention reduces HBM traffic by a factor of 4 to 8, achieving a 2–4× wall-clock speedup purely through memory hierarchy optimization.

Mixture of Experts (MoE) and load balancing

In standard feedforward layers, every parameter evaluates every token. Mixture of Experts (MoE) replaces the single FFN with E independent expert networks, dynamically routing each token to a sparse subset of k experts (commonly k = 2):

H(x)=x·Wg,G(x)=Softmax(TopK(H(x),k)),y=∑i∈TopKG(x)iEi(x)

Mixtral 8x7B has 8 experts of 7B parameters each (~47B total parameters), but routes each token to only 2 experts, executing only ~13B active parameters per forward pass.

Auxiliary load balancing loss

Without regularisation, routers suffer from representation collapse: one or two experts receive all tokens, while the remaining experts receive zero gradient and die. Shazeer et al. introduce an auxiliary load-balancing loss:

Laux=α·E∑i=1EfiPi

where fi=1T∑t=1T1{expert i∈TopK} is the fraction of tokens routed to expert i, and Pi=1T∑t=1TSoftmax(H(xt))i is the average routing probability. Minimizing Laux encourages uniform expert utilization across the batch.

Mamba: selective state-space models

Mamba (Gu & Dao, 2023) replaces attention with a selective continuous-time state space model (SSM):

h′(t)=Ah(t)+Bx(t),y(t)=Ch(t)

Discretized with step size Δ via Zero-Order Hold (ZOH):

A¯=exp(ΔA),B¯=(ΔA)−1(exp(ΔA)−I)·ΔB≈ΔB ht=A¯ht−1+B¯xt,yt=Cht

In linear time-invariant SSMs (such as S4), A, B, C, and Δ are constant across time, allowing the recurrence to be evaluated globally as an FFT convolution: y=x*K. Mamba makes B(x), C(x), and Δ(x) input-dependent functions of token xₜ. This enables selective remembering and forgetting (filtering irrelevant tokens), but breaks the convolution theorem, requiring hardware-aware parallel associative scans. Inference executes in O(1) constant time per token with a fixed-size recurrent state h∈ℝd×N, eliminating the growing KV cache entirely.

KV-cache scaling: Multi-Head vs Grouped-Query Attention

During autoregressive generation, keys and values from earlier tokens are cached in VRAM to prevent quadratic recomputation. The total bytes stored by a KV cache are:

Bytes=2·layers·nkv·dhead·T·batch·byteselem

Consider LLaMA-3 8B: 32 layers, hidden dimension d = 4096, head dimension dhead=128, query heads nq=32, sequence length T=8 192, batch = 1, FP16 (2 bytes/elem):

  • Multi-Head Attention (MHA, nkv=32): 2·32·32·128·8 192·1·2=4 294 967 296 B=4.0 GB
  • Grouped-Query Attention (GQA, nkv=8): 4 query heads share 1 KV head (ratio 4:1): 2·32·8·128·8 192·1·2=1 073 741 824 B=1.0 GB
  • Multi-Query Attention (MQA, nkv=1): All 32 query heads share a single KV head: 2·32·1·128·8 192·1·2=134 217 728 B=128 MB

GQA achieves a 4× reduction in KV-cache memory consumption and memory bandwidth while matching MHA model quality across downstream benchmarks.
