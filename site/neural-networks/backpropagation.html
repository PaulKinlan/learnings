Backpropagation: the chain rule, run backwards

Gradient descent needs the slope of the loss for every weight. Backpropagation computes all of them in one pass backwards through the network, for roughly twice the cost of the forward pass. Without it, training anything large would be out of reach.

All chapters

One slope per weight

The previous chapter measured a slope by nudging a weight both ways and re-running the network. That works, but it takes two forward passes per weight. A model with a billion weights would need two billion forward passes for a single training step.

Backpropagation gets every one of those slopes from one forward pass and one backward pass. For the matrix multiplications that dominate a neural network, the backward pass costs about twice as much as the forward one. That is the figure Kaplan and colleagues use when they count training compute.

The chain rule, on one neuron

Take one neuron with one input. It computes z=wx+b, squashes that to a=σ(z) with the sigmoid, and the loss compares a with the target y: L=(a−y)2.

Each step depends only on the one before it. The chain rule says that the slope of the whole chain is the product of the slopes of its links:

∂L∂w= ∂L∂a· ∂a∂z· ∂z∂w

Each link is easy on its own. The loss changes at 2(a−y) per unit of a. The sigmoid's slope is a(1−a). And z changes by x per unit of w. So:

∂L∂w= 2(a−y)· a(1−a)·x

Notice that the first two factors are shared. The slope for the bias b uses the same two, times ∂z∂b=1. Reusing the shared part instead of recomputing it is the whole trick of backpropagation.

Computation graphs

A real network is far too big to write out by hand like that. Automatic differentiation breaks the calculation into primitive operations (add, multiply, tanh, sigmoid, square) and records them as a graph. Each operation needs to know only one thing: the slope of its output with respect to each of its inputs, its local derivative.

The forward pass computes every node's value and keeps it. The backward pass starts at the loss with ∂L∂L=1 and walks the graph in reverse, multiplying by local derivatives as it goes. When a value feeds more than one operation, the contributions from each one add up:

∂L∂u= ∑v uses u ∂L∂v· ∂v∂u

Visiting the nodes in reverse order of computation guarantees that everything using a node has been visited before the node itself. So each node's gradient is complete by the time it passes that gradient on to its own inputs.

Why backwards?

The chain rule can also run forwards. Pick one input and carry the derivative of every value with respect to it through the graph, alongside the values themselves. This is forward-mode differentiation: one pass gives the slope of every output with respect to that one input. Reverse mode, which is backpropagation, does the opposite: one pass gives the slope of one output with respect to every input.

A network has one output that matters, the loss, and millions or billions of weights. Reverse mode needs one backward pass. Forward mode would need one pass per weight.

The price is memory. The backward pass needs the values the forward pass computed, so training keeps every layer's activations until the backward pass reaches that layer. That is a large part of why training needs much more memory than running the same model. Gradient checkpointing (Chen and colleagues, 2016) trades some of it back: keep only some activations, and recompute the rest during the backward pass.

The same thing with matrices

Real networks work on matrices, not single numbers. Take a layer that multiplies its input X by a weight matrix W:

Y=XW

Its local derivative would be an enormous matrix of every output's slope with respect to every input, and no framework ever builds it. Instead, given the gradient G=∂L∂Y that arrives from the layer above, the backward pass computes:

∂L∂W= XTG ∂L∂X= GWT

Both are ordinary matrix multiplications, the same kind of work as the forward pass. Two of them per layer, against one going forwards, is where “about twice the cost” comes from. This guide's tests check both formulas against finite differences.

Who worked it out

Backpropagation was discovered several times, in different fields, before it became famous.

  1. 1960Henry Kelley's gradient method for optimal flight paths runs a recursion backwards from the end of the trajectory: the same structure, in control theory.
  2. 1962Stuart Dreyfus derives that backward recursion using nothing but the chain rule.
  3. 1962Frank Rosenblatt writes of “back-propagating error correction” in Principles of Neurodynamics, but has no working rule for hidden layers.
  4. 1967Shun'ichi Amari trains a network with an adaptive hidden layer by stochastic gradient descent.
  5. 1970Seppo Linnainmaa's master's thesis describes reverse-mode automatic differentiation in general form. It was published in 1976.
  6. 1974Paul Werbos's PhD thesis proposes using it to train neural networks. He applies it to networks explicitly in 1982.
  7. 1985David Parker and Yann LeCun each arrive at it independently.
  8. 1986Rumelhart, Hinton and Williams show in Nature that backpropagation teaches hidden units useful internal representations.
  9. 1989LeCun and colleagues use it to train a convolutional network that reads handwritten ZIP codes.

The 1986 paper did not invent the algorithm. What it did was show what the algorithm could do. In one experiment a network learned two family trees, and its hidden units came to stand for features such as nationality and generation, which nobody had programmed in. Computers had also become fast enough to run experiments like that.

Nobody writes the backward pass by hand any more

Theano and TensorFlow build a graph of operations first and then differentiate it. PyTorch records operations on a tape as the code runs, much as the Value class behind the widgets on this page does. JAX transforms ordinary Python functions. Underneath, all of them do reverse-mode automatic differentiation.

What this leaves out

  • ReLU has a corner at zero, where its slope is undefined. Frameworks simply pick a value there, usually 0.
  • A gradient that travels back through many layers is a product of many local slopes. If most of them are below 1 it shrinks towards zero; if most are above 1 it blows up. The chapter on activation functions is about exactly that.
  • Whether the brain does anything like backpropagation is still an open question (Lillicrap and colleagues, 2020).
