Backpropagation

Trace the forward values and reverse derivatives of a two-layer network, one operation at a time.

Three milestones, not one invention

Seppo Linnainmaa’s 1970 thesis gave a general reverse accumulation method for differentiating compositions of elementary operations. This is reverse-mode automatic differentiation: record a calculation, then traverse its dependencies backwards.

Paul Werbos’s 1974 Harvard thesis described using such derivatives to adapt nonlinear systems, including the foundations for training multilayer networks. The mathematics predates the wave of popular neural-network applications.

David Rumelhart, Geoffrey Hinton and Ronald Williams’s 1986 Nature paper, “Learning representations by back-propagating errors”, demonstrated learning useful hidden representations and popularised the method. Backpropagation computes gradients; gradient descent is the separate algorithm that uses them to change weights.

The chain rule on a graph

∂L∂w=∂L∂a·∂a∂z·∂z∂w

For z = wx + b, the local derivative ∂z/∂w is x. For tanh(z), it is 1 − tanh²(z). For sigmoid(z), it is a(1 − a). Seed ∂L/∂L = 1, multiply along each edge, and add contributions when a value feeds multiple paths. The displayed decimals are rounded; the graph propagates full JavaScript floating-point values.

Read the trace

The graph is in topological order: every operand appears before the operation using it. A multiplication records both operands, because each operand’s derivative depends on the other. Each reverse click pushes the active node’s accumulated derivative to its children. Intermediate gradients can change again when another downstream path contributes; only a completed reverse pass gives every final gradient.

Try setting v1 to zero. The first hidden unit’s incoming weights then have zero influence on the output, so their gradients vanish. Change the target and repeat: the loss derivative changes sign when prediction crosses target. No numerical finite-difference estimation is needed by backpropagation; the tests use finite differences as an independent check.

A scalar output’s reverse pass visits each graph edge once. Saving intermediate activations costs memory; checkpointing trades extra forward computation for less storage. In practical training, gradients are accumulated across examples before the optimizer updates parameters.
