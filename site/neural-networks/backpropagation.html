Backpropagation

Backpropagation is reverse-mode automatic differentiation applied to a directed acyclic computational graph. This chapter proves why reverse accumulation evaluates all parameter gradients in a single sweep, derives the multivariate fan-out chain rule, traces a complete 2-2-1 network step by step, and analyzes the memory-compute tradeoff of activation checkpointing.

Forward-mode vs. reverse-mode computational complexity

Consider differentiating a general mapping f:ℝn→ℝm whose Jacobian matrix has dimension m×n:

  • Forward-Mode Automatic Differentiation computes directional derivatives (Jacobian-Vector Products, JVPs). Evaluating the full Jacobian requires seeding the forward pass with n standard basis vectors: O(n) forward sweeps.
  • Reverse-Mode Automatic Differentiation propagates adjoint sensitivities backwards (Vector-Jacobian Products, VJPs). Seeding the backward pass at the output requires m backward sweeps: O(m) sweeps.

In deep learning, the objective function produces a single scalar loss: m=1. The parameter space contains n=P weights (millions or billions). Forward-mode autodiff would require P forward passes per training step—an impossible computational cost. Reverse-mode backpropagation computes the exact analytical gradient for all P parameters simultaneously in a single reverse sweep (m=1) at the cost of approximately two forward passes.

The multivariate chain rule: summing over fan-out paths

When an intermediate variable x fans out and influences multiple downstream operations y1,y2,…,yk, the total derivative of the scalar loss L with respect to x is the sum of partial derivatives across all outgoing dependency paths:

∂L∂x=∑j=1k∂L∂yj∂yj∂x 
Forward pass:                         Backward pass (Adjoint accumulation):
     ┌──▶ [ y1 ] ──▶                     ┌──◀ [ ∂L/∂y1 ] ◀──
[ x ]│                               [ x ]│
     └──▶ [ y2 ] ──▶                     └──◀ [ ∂L/∂y2 ] ◀──
                                          ∂L/∂x = (∂L/∂y1 · ∂y1/∂x) + (∂L/∂y2 · ∂y2/∂x)

In implementation, this multivariate rule requires that backward passes initialize parameter gradient buffers with zero and accumulate with addition (+=) as incoming signals arrive. Overwriting gradients instead of adding them drops downstream dependency branches.

2. Backward equations

δout=∂L∂z2=∂L∂y^σ′(z2)=2(y^−y)·y^(1−y^) ∂L∂v=δouth,∂L∂c=δout ∂L∂h=δoutv,δhidden=∂L∂z1=∂L∂h⊙(1−h2) ∂L∂W=δhiddenxT,∂L∂b=δhidden

Each weight gradient is the outer product of the local output sensitivity δ and the incoming input activation x. Computing these derivatives requires storing all forward activations in memory until the reverse pass reaches their corresponding layer.

Memory vs. compute: activation checkpointing

In standard backpropagation, peak memory consumption scales linearly with model depth: O(L·B·d) for L layers, batch size B, and activation width d. For frontier LLMs, caching intermediate activations across 80+ layers with 32K context windows rapidly exhausts GPU VRAM before model weights even load.

Activation checkpointing (Griewank, 1992; Chen et al., 2016)

Activation checkpointing discards intermediate activations during the forward pass, retaining only the inputs to coarse block boundaries (e.g. every L layers):

Forward Pass:
[ x0 ] ──▶ ( Block 1 ) ──▶ [ x1 (saved) ] ──▶ ( Block 2 ) ──▶ [ x2 (saved) ] ──▶ Loss

Backward Pass (Block 2):
1. Recompute intermediate activations inside Block 2 from saved x1
2. Backpropagate gradients through Block 2 back to x1
3. Discard Block 2 activations and repeat for Block 1 from saved x0

By re-evaluating the forward pass of one block at a time during the backward pass, activation memory drops from O(L) to O(L), at the cost of running approximately one extra forward pass (+33% arithmetic compute).
