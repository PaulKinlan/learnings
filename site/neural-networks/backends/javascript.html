JavaScript and typed arrays

Inspect and run a matrix product using contiguous Float32Array storage.

Flat storage and loop order

A row-major M × K matrix stores A[i,k] at i·K + k. Float32Array rounds stored values to 32-bit floats, though ordinary JavaScript arithmetic uses binary64 numbers. In this implementation every accumulated write rounds back to float32.

The i,k,j loop order loads A[i,k] once and walks contiguous rows of B and C. An i,j,k loop is mathematically equivalent but walks B with a stride of N. Cache behaviour and the JIT can matter more than reducing a few source lines.

When plain JavaScript is enough

For small tensors, avoiding transfer and compilation overhead can beat a more elaborate backend. Reuse output arrays and avoid temporary objects in hot loops. Large synchronous loops block input and rendering; run substantial work in a worker or yield between bounded batches. This example is intentionally only four output cells.

The full workbench backend comparison has larger repeatable operations. Do not infer general runtime rankings from one shape or a single cold run.
