Activation functions

Plot a nonlinearity and its derivative, then watch gradients pass through ten layers.

Without a nonlinearity, depth collapses

Composing two affine transforms gives another affine transform. Hidden layers become expressive only when something nonlinear separates them. Sigmoid maps to (0,1), tanh to (−1,1), and ReLU keeps positive values while zeroing negatives.

Sigmoid’s derivative never exceeds 1/4. With unit weights, ten chained derivatives are at most (1/4)¹⁰ ≈ 0.000000954. The table below multiplies the actual local derivatives, which may be even smaller. This is a scalar illustration, not the full matrix Jacobian of a wide network.

Which problem does each function solve?

ReLU preserves slope 1 on positive inputs, but a negative preactivation receives no gradient. Leaky ReLU keeps a small negative slope. Tanh is zero-centred yet saturates in both tails. A hard step is useful for logical classification but its derivative is zero almost everywhere, so ordinary gradient descent cannot train it.

GELU smoothly gates by an approximation to a Gaussian cumulative distribution. This plot uses the documented tanh approximation. SiLU, also called Swish, is x·sigmoid(x). SwiGLU is not a scalar activation in this dropdown: it computes SiLU(xW₁) ⊙ (xW₂), followed by an output projection, so it has two learned branches.

Try sigmoid with weight 1 and input 3, then ReLU with input 0.5. Raise the weight to 2: preserving local slopes can now produce exploding gradients. Architecture, initialization, normalization and residual connections matter alongside the activation.
