Architectures: MLPs, CNNs and RNNs

The same weighted sums, with different assumptions about how information should flow.

Three useful inductive biases

An MLP connects every input to hidden units. It is flexible but does not inherently know that adjacent image pixels are related. A CNN shares local filters over space: features translate with the input away from borders, and pooling can reduce sensitivity to small shifts.

An RNN reuses a state update hₜ = f(Wxₜ + Uhₜ₋₁ + b) over time. Its parameter count does not grow with sequence length, but training unfolds the recurrence and backpropagates through every step. Long products of recurrent Jacobians can vanish or explode. LSTM and GRU add gates to regulate state updates.

A residual block computes h + F(h), making an identity path available when shapes match. Its derivative includes I + ∂F/∂h rather than only ∂F/∂h. This helps optimization but does not guarantee that every deep model trains.
