Loss, softmax and calibration

Turn scores into probabilities, compare scoring rules and test the effect of temperature.

A loss defines what learning rewards

Mean squared error averages squared differences between predictions and targets. It is natural for real-valued regression. Cross-entropy for a labelled class is −log p(true class), so confident mistakes receive a large penalty. For logits z, softmax exponentiates and normalises them; subtracting the largest logit before exponentiation prevents avoidable overflow without changing the result.

Brier score is not the same reduction as MSE

Here the multiclass Brier score is Σᵢ(pᵢ − yᵢ)², while MSE averages those same four terms. Brier is therefore four times the displayed MSE and ranges from 0 to 2. Some libraries use different scaling conventions; always state yours. Both cross-entropy and Brier are proper scoring rules in expectation.

Entropy −Σp log p measures uncertainty, not accuracy. Lowering temperature can make a wrong answer more confidently wrong. Make class 1’s logit largest, choose class 4 as the target, then lower τ. Accuracy is unchanged but cross-entropy rises sharply.

A calibrated predictor gets about 80% of its 80%-confidence predictions correct on representative held-out data. One prediction cannot demonstrate calibration. Temperature scaling fits a positive τ on a held-out calibration set, typically by minimising cross-entropy, then evaluates on a separate test set. It does not change the argmax class or repair distribution shift automatically.
