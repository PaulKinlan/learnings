1. Perceptrons, Feedforward MLPs & Backpropagation (1958–1986)

In 1958, Frank Rosenblatt introduced the Perceptron, a linear threshold unit computing ŷ = step(w · x + b). Eleven years later, Marvin Minsky and Seymour Papert proved in Perceptrons (1969) that a single linear layer defines only a single flat hyperplane w0x0 + w1x1 + b = 0 in input space—making it mathematically impossible to represent non-linearly separable predicates such as XOR parity (where opposite corners of the unit square share a class).

The resolution—championed by Rumelhart, Hinton, and Williams (1986) building on Linnainmaa's (1970) reverse-mode automatic differentiation—is to stack hidden layers interleaved with point-wise non-linear activation functions σ(z). Geometrically, each hidden layer folds and stretches the coordinate manifold along dout hyperplanes so that classes tangled in input space become linearly separable at the final readout layer.

Training a multilayer network requires computing how a nudge to any weight Wi,j(l) in layer l affects the scalar loss L(ŷ, y) at layer L. Naive finite differences (perturbing each of P parameters one by one) requires O(P) forward passes per step. Reverse-Mode Backpropagation computes the exact gradient for all P parameters in a single backward sweep at the cost of roughly one extra forward pass by caching each layer's pre-activation z(l) and activation a(l) and propagating the local error sensitivity δ(l) = ∂L / ∂z(l) from output to input:

Forward: z(l) = a(l−1)W(l) + b(l),   a(l) = σ(z(l))  |  Output Error (Sigmoid + BCE): δ(L) = ∂L/∂z(L) = ŷ − y  |  Backward: δ(l) = (δ(l+1)(W(l+1))T) ⊙ σ'(z(l)),   ∇W(l)L = (a(l−1))Tδ(l),   ∇b(l)L = δ(l)

2. Convolutional Neural Networks: Spatial Priors, Weight Sharing & Pooling (1989–2012)

Why not feed images directly into a dense MLP? Consider a modest 256 × 256 RGB image (196,608 inputs). A single dense layer with 1,000 hidden units requires 196.6 million weights—and worse, if an object shifts by just 2 pixels, every input lands on a completely different weight, forcing the network to re-learn edge detectors at every (x, y) coordinate from scratch.

Convolutional Neural Networks—pioneered by Fukushima's Neocognitron (1980), LeCun's LeNet-5 (1989/1998) for handwritten zip codes, and scaled to GPUs by Krizhevsky, Sutskever, and Hinton's AlexNet (2012)—encode two physical priors of natural signals directly into the architecture:

  • Locality & Sparse Connectivity: Early visual features (oriented edges, corners, strokes) depend only on a small local neighborhood k × k (here 3 × 3 pixels). Stacking convolutional layers grows the effective receptive field linearly with depth (two 3 × 3 layers see a 5 × 5 window; three see 7 × 7).
  • Spatial Weight Sharing (Translation Equivariance): The exact same 3 × 3 kernel tensor K(f) (only 9 weights + 1 bias!) is slid across every row r and column c of the image. Shifting the input shifts the resulting feature map identically: f(TΔr,Δc I) = TΔr,Δc f(I).
  • Local Max-Pooling & Switch Routing: A 2 × 2 stride-2 MaxPool layer outputs the maximum activation in each 2 × 2 patch, granting local translation invariance. During backpropagation, MaxPool acts as a router: it records the argmax index during the forward pass and routes 100% of the upstream gradient ∂L/∂p exclusively to that winning pixel while zeroing the other three.
Forward: Z(f)r,c = bf + ∑u=0..2 ∑v=0..2 Ir+u, c+v · K(f)u,v  |  Backward Filter Grad: ∂L/∂K(f)u,v = ∑r,c Ir+u, c+v · δ(f)r,c  |  Input Grad: ∂L/∂I = δ ∗ rot180°(K)

3. Recurrent Neural Networks, BPTT & Gated Memory (LSTM / GRU) (1986–1997)

Feedforward MLPs and CNNs assume fixed-size inputs with no persistent memory across time. To process sequences x0, x1, …, xT−1 of arbitrary length (speech, text, time series, control loops), Jordan (1986) and Elman (1990) introduced Recurrent Neural Networks (RNNs), which maintain a hidden state vector ht ∈ ℝD updated recurrently at every timestep: ht = tanh(Wxh xt + Whh ht−1 + bh).

Why Vanilla RNNs Struggle with Long-Term Dependencies (Hochreiter, 1991; Bengio et al., 1994): When we unroll the recurrence across T timesteps and apply the chain rule—an algorithm known as Backpropagation Through Time (BPTT)—the sensitivity of the final loss LT to an early hidden state hk is a product of T − k Jacobians:

BPTT Jacobian Chain: ∂hT / ∂hk = ∏j=k+1..T (∂hj / ∂hj−1) = ∏j=k+1..T diag(1 − hj2) · WhhT  |  GRU Additive Highway: ht = (1 − zt) ⊙ ht−1 + zt ⊙ h̃t  ⇒  ∂ht/∂ht−1 = diag(1 − zt) + …
  • Vanishing vs. Exploding Gradients: Because diag(1 − hj2) is bounded in [0, 1] and WhhT is multiplied repeatedly T − k times, if the largest eigenvalue (spectral radius) ρ(Whh) < 1, the gradient norm ‖∂LT/∂h0‖ decays exponentially like ρT → 0—wiping out any learning signal from token x0! Conversely, if ρ(Whh) > 1, gradients grow exponentially like ρT → ∞ (requiring global gradient norm clipping).
  • The Gated Solution — LSTM (Hochreiter & Schmidhuber, 1997) & GRU (Cho et al., 2014): Instead of overwriting ht through a multiplicative matrix + saturating tanh at every step, Long Short-Term Memory (LSTM) and the Gated Recurrent Unit (GRU) introduce a learnable sigmoid Update / Forget Gate zt = σ(Wxzxt + Whzht−1 + bz) ∈ (0, 1) that interpolates additively between the old state and the new candidate state: ht = (1 − zt) ⊙ ht−1 + zt ⊙ h̃t. When the gate remains closed (zt → 0) across distractor tokens, ∂ht/∂ht−1 ≈ I—forming a Constant Error Carousel that carries both the memory of x0 forward and the error gradient ∂LT/∂h0 backward across dozens or hundreds of timesteps without attenuation!

4. Very Deep Neural Networks: Residual Highways (ResNets), Normalization & Init (2015–Present)

By 2014, researchers discovered a counterintuitive barrier when stacking 20, 50, or 100+ layers: even with ReLU activations and careful initialization, plain deep networks had higher training error than shallower networks (the Degradation Problem). Three interlocking mechanisms govern whether signals and gradients survive across extreme depth:

  • 1. Variance-Preserving Weight Initialization (Glorot/Xavier 2010 & Kaiming He 2015): For a linear layer zj = ∑i=1..D wij ai with independent zero-mean weights of variance σw2, the output variance is Var(zj) = D · σw2 · Var(ai). If D · σw2 ≠ 1, after L layers the signal variance scales as (D · σw2)L—either vanishing to 0 (when weights are too small) or exploding to ∞ (when weights are too large). Xavier init sets σw = √(1/D) for linear/tanh layers; Kaiming He init sets σw = √(2/D) to compensate for ReLU/GELU zeroing half the distribution.
  • 2. Layer Normalization & Pre-RMSNorm (Ba et al. 2016; Zhang & Sennrich 2019): Even with ideal initialization, parameter updates during training cause activation scales to drift across layers (internal covariate shift). RMSNorm rescales each layer's input vector to unit root-mean-square before the weight projection: RMSNorm(x) = (x / √(mean(x²) + ε)) ⊙ γ, ensuring every block receives well-conditioned O(1) inputs regardless of depth.
  • 3. Residual Skip Highways (He, Zhang, Ren & Sun, 2015): Instead of forcing layer l to learn a full mapping x(l) = Fl(x(l−1)), a Residual Block learns an additive perturbation around an identity skip path: x(l) = x(l−1) + Fl(RMSNorm(x(l−1))). Unrolling this recurrence to layer L reveals why 100+ layer ResNets and modern Pre-LN Transformers train effortlessly:
Forward Residual Stream: x(L) = x(l) + ∑k=l..L−1 Fk(x(k))  |  Backward Jacobian Highway: ∂L / ∂x(l) = (∂L / ∂x(L)) · (I + ∂/∂x(l) ∑k=l..L−1 Fk(x(k)))

Look at the + I (identity matrix) inside the backward Jacobian above: even if the intermediate weight matrices inside Fk have small singular values, the error gradient ∂L/∂x(L) from the loss head is added directly to every earlier layer ∂L/∂x(l) without being multiplied through a chain of L − l matrices!

5. Transformers & Scaled Dot-Product Self-Attention (2017–Present)

Even with Gated GRUs and LSTMs, recurrent networks suffer from two structural bottlenecks: (1) step t cannot be computed until step t − 1 finishes, preventing parallel GPU/TPU training across the sequence dimension T; and (2) all historical information from tokens 0 … t − 1 must be compressed into a single fixed-width vector ht−1 ∈ ℝD.

In Attention Is All You Need (2017), Vaswani et al. eliminated recurrence entirely in favor of Multi-Head Self-Attention. Every token position i ∈ {0 … T−1} projects its representation xi into three distinct subspace vectors for each head h:

  • Query qi = xi WQ(h): What feature or context is token i looking for?
  • Key kj = xj WK(h): What routing descriptor or address does token j advertise?
  • Value vj = xj WV(h): What payload content should token j transmit if attended to?

Why the 1 / √dk Scaling Factor Is Critical: If the components of qi and kj have zero mean and unit variance, their dot product qi · kj = ∑m=1..dk qim kjm has mean 0 and variance dk (standard deviation √dk). For large head dimension dk, unscaled dot products grow large in magnitude, pushing softmax into extreme one-hot saturation where the Softmax Jacobian ∂Pij/∂Sik = Pij(δjk − Pik) vanishes to zero! Dividing by √dk restores unit variance prior to softmax.

Attention(Q, K, V) = softmax((Q KT) / √dk + M) V  |  Softmax Row Jacobian: ∂L / ∂Si,j = Pi,j · (∂L/∂Pi,j − ∑k Pi,k · ∂L/∂Pi,k)

6. Diffusion Models: Continuous Image DDPM & Discrete Masked Text Diffusion (2020–Present)

Directly mapping a single random latent vector z ~ N(0, I) to a complex high-dimensional data manifold (such as natural images or whole paragraphs of text) in a single pass forces a neural network to solve an intractable global coordination problem all at once: GANs suffer from adversarial mode collapse, while single-step VAEs average over modes and produce blurry outputs.

Diffusion Models (Sohl-Dickstein et al., 2015; Song & Ermon, 2019; Ho, Jain & Abbeel, 2020) decompose generation into a trajectory of easy, local denoising refinements. They pair a fixed, parameter-free forward corruption process q(x1:T | x0) that gradually destroys all structure in data x0 over T steps with a learned reverse generative process pθ(xt−1 | xt) that reconstructs the signal step by step.

Part I — Mathematical Anatomy of Continuous Gaussian Diffusion (DDPM & Score Matching)

  1. Forward Markov Chain & the Closed-Form Marginal Shortcut: Given a clean data vector x0 ∈ ℝD and a variance schedule β1 < β2 < … < βT ∈ (0, 1), each forward step attenuates the signal by √(1 − βt) and injects Gaussian noise of variance βt: q(xt | xt−1) = N(xt; √(1 − βt) xt−1, βt I). Because the sum of independent Gaussians is still Gaussian, defining αt = 1 − βt and the cumulative signal retention product ᾱt = ∏s=1..t αs yields a remarkable closed-form shortcut—we can sample noisy state xt at any arbitrary timestep t in O(1) without unrolling steps 1 … t − 1:
    Closed-Form Forward Marginal: xt = √ᾱt · x0 + √(1 − ᾱt) · ε,    where ε ~ N(0, I),    SNR(t) = ᾱt / (1 − ᾱt)
  2. Variational Lower Bound (ELBO), Tweedie's Formula & Stein Score Equivalence: Although the true reverse transition q(xt−1 | xt) is intractable without knowing x0, Bayes' rule shows that conditioned on x0 it is an exact Gaussian q(xt−1 | xt, x0) = N(xt−1; μ̃t(xt, x0), β̃t I). Substituting our closed-form equation x0 = (xt − √(1 − ᾱt) ε) / √ᾱt into the KL divergence DKL(q(xt−1|xt,x0) ‖ pθ(xt−1|xt)) collapses the entire variational bound into Ho et al.'s noise-prediction MSE objective:
    Lsimple(θ) = Et ~ Uniform(1..T), x0, ε ~ N(0,I) [ ‖ ε − εθ(√ᾱt x0 + √(1 − ᾱt) ε, t) ‖22 ]
    By Tweedie's Formula, predicting the noise vector εθ(xt, t) is mathematically identical (up to a scalar factor) to estimating the Stein Score Function—the gradient of the log probability density of the noisy data distribution: ∇xt log q(xt) = − εθ(xt, t) / √(1 − ᾱt). Every reverse step literally nudges xt uphill along the log-density gradient toward high-probability data manifolds!
  3. Reverse Sampling: Stochastic Langevin (DDPM) vs. Deterministic ODE (DDIM) & Classifier-Free Guidance (CFG): Starting from pure Gaussian noise xT ~ N(0, I), the reverse sampler steps from t = T down to 1:
    Reverse Step: xt−1 = (1 / √αt) · ( xt − ((1 − αt) / √(1 − ᾱt)) · εθ(xt, t) ) + σt z,    z ~ N(0, I)
    Setting σt = √βt yields stochastic ancestral DDPM sampling (overdamped Langevin dynamics); setting σt = 0 (Song et al.'s DDIM) converts the process into a deterministic Probability Flow ODE that can skip steps (e.g., 1000 → 20 steps). To condition generation on a prompt or class label c, Classifier-Free Guidance (Ho & Salimans, 2022) linearly extrapolates away from the unconditional score: ε̃θ(xt, t, c) = (1 + w) · εθ(xt, t, c) − w · εθ(xt, t, ∅).

Part II — Discrete Masked Text Diffusion (D3PM, SEDD & MDLM / Mercury)

Why can't we apply standard Gaussian DDPM directly to text tokens? Because token IDs ("neural" = 412, "gradients" = 891) are discrete categorical indices—adding 0.15 · ε to an integer index has no geometry. Instead, Discrete Diffusion Models (Austin et al., 2021 D3PM; Lou et al., 2024 SEDD; Sahoo et al., 2024 MDLM) define a Continuous-Time Markov Chain (CTMC) directly over the discrete vocabulary V ∪ {[MASK]} using an absorbing state [MASK]:

  • Forward Masking Schedule: At noise level t ∈ [0, 1] with survival probability αt = 1 − t, each token x0(i) independently remains intact with probability αt or transitions to the absorbing [MASK] state with probability 1 − αt: q(zt(i) | x0(i)) = αt δx0(i) + (1 − αt) δ[MASK]. At t = 1, the entire sequence is [MASK, MASK, …, MASK].
  • SUBS Parameterization & Bidirectional Denoising Objective: Unlike an autoregressive GPT (which must use a causal triangular mask j ≤ i and can only condition on left context), a Masked Diffusion Language Model uses a full bidirectional Transformer encoder. Under the SUBS (Substitution) parameterization, any already-unmasked token at position i is copied through with probability 1 (carry-over unmasked tokens), and the cross-entropy loss is evaluated exclusively on currently masked positions weighted by the continuous-time NELBO rate −α't / (1 − αt) = 1 / t:
    LMDLM(θ) = Et ~ U(0,1), zt ~ q(zt|x0) [ (1 / t) · ∑i : zt(i) = [MASK] − log pθ(x0(i) | zt) ]
  • Parallel Confidence-Guided Unmasking (Why Diffusion LMs Generate in O(K) Steps Instead of O(L)): To generate a sequence of length L, an autoregressive LLM must execute L sequential forward passes (token 1 → token 2 → … → token L). A Masked Diffusion LM starts with L [MASK] tokens, predicts categorical distributions pθ(x0(i) | zt) across all masked positions in a single bidirectional pass, and unmasks the top-k positions with the highest confidence maxv pθ(v | zt) in parallel—crystallizing islands of high-certainty words across the whole sentence simultaneously in S ≪ L steps!

7. Decision Models & Single-Pass Pointer Readout Heads (2025–Present)

When software systems use an LLM to route a ticket, select a tool, or score risk, autoregressive token generation is both wasteful and brittle: the model must emit dozens of syntax tokens ({"choice": "..."}), token probabilities fragment across surface synonyms, and raw softmax probabilities are notoriously overconfident on out-of-distribution inputs.

As detailed in our Decision Models report (Jev, Kev, and Laya), a Decision Pointer Head packs the state and candidate options into a structured sequence with reserved option delimiters (‹0› … ‹K−1› or pre-mask slots), runs a single forward pass, and computes the inner product between the projected state representation hstate and each option delimiter's hidden vector h‹k›. Crucially, it decouples Choice (which option wins under temperature-calibrated softmax) from the Act / Review Gate (which uses margin and entropy features of the raw distribution to abstain when evidence is ambiguous).

zk = (Wq hstate)T (Wk h‹k›) / (√d · T),   p = softmax(z),   Confidence = 0.65 · p(1) + 0.35 · (p(1) − p(2)),   Gate ∈ {act, review}

Reverse-Mode Autograd & Decoupled AdamW Update

Every neural network training loop follows four exact steps: (1) forward pass caching intermediate pre-activations z(l) and activations a(l), (2) loss evaluation at the output head, (3) reverse-mode chain-rule propagation of δ(l) = ∂L / ∂z(l), and (4) parameter update: 

// Output layer gradient for Sigmoid + Binary Cross-Entropy simplifies to (p - y) / N
for (let i = 0; i < N; i++) dZ[i] = (probs[i] - Y[i]) / N;

// Backpropagate through hidden layers l = L-1 ... 0
for (let l = layers.length - 1; l >= 0; l--) {
  // 1. Parameter gradients: dW = prevA^T · dZ, db = sum(dZ)
  // 2. Propagate error to previous layer: dPrevZ = (dZ · W^T) * activationGrad(prevZ)
  // 3. Decoupled AdamW update:
  m = beta1 * m + (1 - beta1) * g;
  v = beta2 * v + (1 - beta2) * (g * g);
  w = w * (1 - lr * weightDecay) - lr * (mHat / (Math.sqrt(vHat) + 1e-8));
}

Extending the Workbench with registerBlockType()

You can register new neural network paradigms into BLOCK_REGISTRY from the browser console or module code at any time: 

import { registerBlockType } from "./engine.js";

registerBlockType({
  type: "griffin_rg_lru",
  label: "Real-Gated Linear Recurrent Unit (RG-LRU)",
  category: "recurrent",
  description: "Diagonal gated linear recurrence with hardware-efficient scan.",
  computeStats(shape) {
    return {
      outShape: { ...shape },
      params: 3 * shape.d * shape.d,
      flops: 6 * shape.t * shape.d * shape.d
    };
  }
});
