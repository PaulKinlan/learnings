Three ideas carry the whole subject

A neuron is a weighted sum followed by a squash. Multiply each input by a weight, add them up with a bias, and pass the total through a function f:

y=f( ∑i=1n wixi+b )

Explore the perceptron chapter. Enable JavaScript for the live playground.

Learning means walking downhill on a loss. A loss L scores how wrong the network is. Each weight takes a small step η against its slope:

w←w−η ∂L∂w

Explore gradient descent. Enable JavaScript for the live playground.

Backpropagation finds every slope at once by applying the chain rule from the output back towards the inputs:

∂L∂w= ∂L∂a· ∂a∂z· ∂z∂w

Explore backpropagation. Enable JavaScript for the live playground.

Everything else (convolutions, attention, mixture-of-experts) changes which weighted sums get computed and in what shape. These three ideas stay the same throughout.

Eighty years in fourteen dates

  1. 1943McCulloch and Pitts show that networks of on/off threshold units can compute any logical function.
  2. 1958Rosenblatt's perceptron learns its own weights from examples.
  3. 1969Minsky and Papert analyse restricted perceptrons; XOR illustrates the limitation of a single linear threshold.
  4. 1970Linnainmaa describes reverse-mode automatic differentiation, the algorithm inside backpropagation.
  5. 1986Rumelhart, Hinton and Williams show backpropagation teaching hidden layers useful features.
  6. 1989LeCun trains a convolutional network to read handwritten ZIP codes.
  7. 1997Hochreiter and Schmidhuber's LSTM keeps gradients alive over long sequences.
  8. 2012AlexNet, trained on two GPUs, wins ImageNet by a wide margin.
  9. 2015Residual connections make networks with 100+ layers trainable.
  10. 2017“Attention Is All You Need” introduces the Transformer.
  11. 2020GPT-3 shows how far scaling a Transformer goes.
  12. 2022FlashAttention speeds attention up by reorganising memory traffic, with no approximation.
  13. 2023Mamba revives state space models; Mixtral popularises sparse mixture-of-experts.
  14. 2024DeepSeek-V3 activates 37B of its 671B parameters per token.
