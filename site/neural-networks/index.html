1. Perceptrons, Feedforward MLPs & Backpropagation (1958–1986)

Marvin Minsky and Seymour Papert showed in 1969 that a single-layer Perceptron ([2, 1]) can only draw a flat linear hyperplane—making non-linearly separable problems like XOR impossible. Adding hidden layers with non-linear activations warps the input space so a linear readout can separate arbitrary manifolds, trained end-to-end via reverse-mode automatic differentiation (Backpropagation).

Forward: z(l) = a(l−1)W(l) + b(l),   a(l) = σ(z(l))  |  Backward: δ(l) = (δ(l+1)(W(l+1))T) ⊙ σ'(z(l)),   ∇W(l)L = (a(l−1))Tδ(l)

2. Convolutional Neural Networks: Spatial Priors & Weight Sharing (1989–2012)

Flattening an image into a dense MLP throws away 2D spatial topology and explodes parameter count. Convolutional Neural Networks (CNNs) slide small learnable filters (here four 3×3 kernels) across the input, sharing weights across every pixel location and pooling local maxima for translation invariance.

(I ∗ K)r,c = b + ∑u=0..2 ∑v=0..2 Ir+u, c+v · Ku,v  →  ReLU  →  MaxPool2D(2×2)  →  Linear(36 → 4)

3. Transformers & Scaled Dot-Product Self-Attention (2017–Present)

Recurrent networks compressed history through a sequential bottleneck. The Transformer replaced recurrence with Multi-Head Self-Attention, letting every token position project Query (Q), Key (K), and Value (V) vectors and route information directly across any distance in O(1) sequential depth.

Attention(Q, K, V) = softmax((Q KT) / √dk + M) V

4. Diffusion Models: Continuous Image DDPM & Discrete Masked Text Diffusion

Instead of predicting outputs in one shot, Diffusion Models define a known forward corruption process that destroys structure—either by adding Gaussian noise to continuous pixels (DDPM) or masking discrete tokens to [MASK] (Masked Diffusion Language Models / MDLM)—and train a neural network to invert the corruption step by step.

Image DDPM: xt = √ᾱt x0 + √(1 − ᾱt) ε,   L = ‖ε − εθ(xt, t)‖²  |  Text MDLM: q(xt | x0) masks tokens w.p. γ(t)=t/T; reverse unmasks top-confidence positions in parallel.

5. Decision Models & Single-Pass Pointer Readout Heads

Autoregressive generation is poorly suited for software branches that need calibrated probabilities over fixed choices and a principled right to abstain. As explored in our Decision Models report (Jev, Kev, Laya), a Decision Pointer Head projects the final hidden state hlast against option-delimiter hidden states H‹0›..‹K−1› in a single forward pass, applies temperature scaling T, and gates execution via an entropy-aware abstention head.

zk = (Wq hlast)T (Wk h‹k›) / (√d · T),   Confidence = 1 − H(p) / ln(K),   Gate ∈ {act, review}

How the In-Memory Raw WebAssembly (wasm32) GEMM Kernel Works

In site/neural-networks/engine.js, buildWasmGemmBytes() constructs a valid 183-byte WebAssembly binary module directly in a Uint8Array—with zero external `.wasm` files or C/Rust compilers. Both JavaScript and WebAssembly share a contiguous WebAssembly.Memory buffer viewed as a Float32Array: 

;; Disassembly of the in-memory compiled gemm_f32(aPtr, bPtr, cPtr, M, K, N) kernel
(func $gemm_f32 (export "gemm_f32")
  (param $aPtr i32) (param $bPtr i32) (param $cPtr i32)
  (param $M i32) (param $K i32) (param $N i32)
  (local $i i32) (local $j i32) (local $k i32) (local $sum f32)
  ;; Triple nested loop over M × N × K reading/writing linear memory in 4-byte f32 strides:
  ;; sum += f32.load(aPtr + ((i * K + k) << 2)) * f32.load(bPtr + ((k * N + j) << 2))
  ;; f32.store(cPtr + ((i * N + j) << 2), sum)

Reverse-Mode Autograd & Decoupled AdamW Update

Every neural network training loop follows four exact steps: (1) forward pass caching intermediate pre-activations z(l) and activations a(l), (2) loss evaluation at the output head, (3) reverse-mode chain-rule propagation of δ(l) = ∂L / ∂z(l), and (4) parameter update: 

// Output layer gradient for Sigmoid + Binary Cross-Entropy simplifies to (p - y) / N
for (let i = 0; i < N; i++) dZ[i] = (probs[i] - Y[i]) / N;

// Backpropagate through hidden layers l = L-1 ... 0
for (let l = layers.length - 1; l >= 0; l--) {
  // 1. Parameter gradients: dW = prevA^T · dZ, db = sum(dZ)
  // 2. Propagate error to previous layer: dPrevZ = (dZ · W^T) * activationGrad(prevZ)
  // 3. Decoupled AdamW update:
  m = beta1 * m + (1 - beta1) * g;
  v = beta2 * v + (1 - beta2) * (g * g);
  w = w * (1 - lr * weightDecay) - lr * (mHat / (Math.sqrt(vHat) + 1e-8));
}

Backpropagating Through Scaled Dot-Product Self-Attention

In MicroTransformer.trainEpoch(), gradients flow backward from the output logits through the residual stream into the attention value projection V and attention weight matrix A = softmax(QKT / √dk). Because each row of A is a probability distribution summing to 1, its Jacobian couples all columns in that row: 

// Softmax row Jacobian: dScore[i, j] = A[i, j] * (dA[i, j] - sum_m(A[i, m] * dA[i, m])) / sqrt(d_k)
let rowDot = 0;
for (let j = 0; j < T; j++) rowDot += W[i * T + j] * dW[i * T + j];
for (let j = 0; j < T; j++) {
  if (causal && j > i) continue;
  const dScore = W[i * T + j] * (dW[i * T + j] - rowDot) * invSqrtDh;
  for (let d = 0; d < Dh; d++) {
    dQ[i * D + hOffset + d] += dScore * K[j * D + hOffset + d];
    dK[j * D + hOffset + d] += dScore * Q[i * D + hOffset + d];
  }
}

Continuous Image DDPM vs Discrete Masked Text Diffusion

Both continuous and discrete diffusion invert a known forward corruption schedule:

  • Continuous DDPM (MicroDDPM): Defines variance schedule β1…βT, αt = 1 − βt, and cumulative signal retention ᾱt = ∏s=1..t αs. Any timestep t can be sampled in closed form via xt = √ᾱt x0 + √(1 − ᾱt) ε with ε ~ N(0, I). The network minimizes ‖ε − εθ(xt, t)‖², and generation iterates backward from xT ~ N(0, I) to x0:
    xt−1 = (1 / √αt) · (xt − (βt / √(1 − ᾱt)) · εθ(xt, t)) + σt z
  • Discrete Masked Text Diffusion (MaskedTextDiffusion): Replaces Gaussian noise with an absorbing [MASK] token. At noise level γ(t) = t / T, each token transitions independently to [MASK] with probability γ(t). A bidirectional model predicts clean token categorical distributions pθ(x0(i) | xt) across all masked slots simultaneously. During inference, the sampler unmasks the highest-confidence positions in parallel at each step—allowing islands of certainty across the sentence to crystallize simultaneously.

Extending the Workbench with registerBlockType()

You can register new neural network paradigms into BLOCK_REGISTRY from the browser console or module code at any time: 

import { registerBlockType } from "./engine.js";

registerBlockType({
  type: "griffin_rg_lru",
  label: "Real-Gated Linear Recurrent Unit (RG-LRU)",
  category: "recurrent",
  description: "Diagonal gated linear recurrence with hardware-efficient scan.",
  computeStats(shape) {
    return {
      outShape: { ...shape },
      params: 3 * shape.d * shape.d,
      flops: 6 * shape.t * shape.d * shape.d
    };
  }
});
